Search Enhancer

Highlight keywords with pop animation, label result types, and hide ads on Google / Bing / Baidu — and now ANY site with a search box.

🎯 Keyword Pop / 关键词弹跳突出 LIVE

Search terms get a bounce/pop animation + glow, making them instantly eye-catching.

🌐 Universal Mode / 全站通用模式 NEW

When ON, Search Enhancer will highlight keywords on ANY website — not just Google/Bing/Baidu. Works on itch.io, Steam, GitHub, V2EX, or any site with a search box.

How it works:
  • Detects search queries from URL params (?q=, ?query=, ?search=, ?s=, ?wd=, ?keyword=, etc.)
  • Highlights matching keywords anywhere on the page (titles, descriptions, paragraphs, links)
  • Works with single-page apps (SPA) — auto-reruns when you navigate or scroll new content
  • Try it: go to itch.io, search "puzzle", watch all "puzzle" words light up in soft yellow
